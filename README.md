# GitHub Basics Practice

This repository is created to learn and practice the basics of Git and GitHub.

It covers basic tasks such as:

* Creating and working with branches
* Publishing a branch
* Making commits
* Merging branches
* Pushing and pulling changes
* Working with a GitHub repository

This is a practice repository for learning GitHub workflows and getting comfortable with version control for the IEAP Masters program.
